# Changelog

All notable changes to the Salesforce Architecture Trainer will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2023-10-15

### Added
- Initial Flask application conversion from JavaScript version
- 19 educational modules on Salesforce architecture
- User progress tracking using Flask sessions
- Interactive quizzes in each module
- Dark/light theme toggle
- Responsive UI using Bootstrap 5
- Command-line arguments for host and port configuration

### Changed
- Simplified UI compared to original JavaScript version
- Improved module navigation

### Removed
- Original JavaScript application files (app.js, styles.css, index.html)
- Dependency on custom JavaScript libraries

## [Future Plans]

Future development plans include:
- User authentication
- Database storage for progress tracking
- Additional modules on new Salesforce architecture topics
- Export/import functionality for progress
- Improved quiz experiences
